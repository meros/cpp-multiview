# Fonts

Self-hosted, Latin subset, from Google Fonts. Both are licensed under the SIL Open Font License 1.1 (`OFL.txt`).

| File | Family | Use | Source |
|---|---|---|---|
| `shantell-sans-700-latin.woff2` | Shantell Sans, weight 700 | display titles, stepper label, stat numbers | https://github.com/arrowtype/shantell-sans (© The Shantell Sans Project Authors) |
| `nunito-400-700-latin.woff2` | Nunito, weights 400 to 700 (variable) | body text | https://github.com/googlefonts/nunito (© The Nunito Project Authors) |

The page works without them: the font stacks in `css/tokens.css` fall back to system faces.
